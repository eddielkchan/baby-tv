# 📺 寶寶電視 Baby TV

一個給小朋友使用的「白名單 YouTube 播放器」。

家長預先設定好影片清單,小朋友只能觀看清單內的影片 —— **沒有搜尋、沒有演算法推薦、沒有留言區**,影片播完會自動播下一條,不會出現「相關影片」畫面。

適合覺得 YouTube Kids 過濾不夠嚴格、想 100% 控制小朋友觀看內容的家長。

## ✨ 功能

- **白名單片單** —— 只播家長加入的影片,小朋友無法離開這個範圍
- **電視台分類** —— 影片可分類為「📚 教育台」「🎵 兒歌台」等,小朋友先選台再選片
- **自動連播** —— 影片播完自動跳到同一個台的下一條,循環播放,全程不會出現 YouTube 推薦畫面
- **每日限時** —— 可設定每天觀看上限(例如 30 分鐘),時間到自動鎖定,顯示「今日睇完喇 🌙」;家長輸入密碼可加時 15 分鐘
- **家長設定頁** —— 按右上角 ⚙️ 並輸入密碼,即可在 App 內直接加減影片、分類、設定限時、更改密碼
- **跨平台** —— 同一條網址,iPhone / iPad / Android / Windows / Mac 都能使用

## 🚀 自己架設一個(免費)

整個 App 只是一個 HTML 檔案,用 GitHub Pages 免費託管:

1. 註冊 [GitHub](https://github.com) 帳號
2. 建立一個新 repository(名字自訂,例如 `baby-tv`),**Visibility 必須選 Public**
3. 將本 repo 的 `index.html` 上傳到你的 repository
4. 到 repository 的 **Settings → Pages**,Source 選「Deploy from a branch」,Branch 選 `main`,按 Save
5. 等待 1–2 分鐘,你的 App 就會出現在:
   `https://你的用戶名.github.io/baby-tv/`

> ⚠️ 不能直接雙擊 HTML 檔案在本機使用(file:// 方式開啟會出現 Error 153),YouTube 嵌入式播放器要求必須從正式網址載入,所以需要放上 GitHub Pages 或其他網頁空間。

## 👶 小朋友怎樣用

1. 按一個台(如果只有一個台,這行按鈕會自動隱藏)
2. 按一條片的縮圖
3. 之後就不用再碰 —— 影片會在同一個台內自動連播、循環

> 💡 iOS 限制:第一次可能需要按一下播放器才會開始播放(Apple 對自動播放的限制),之後的自動連播不受影響。

## 👨‍👩‍👧 家長設定

1. 按右上角 **⚙️** 按鈕
2. 輸入密碼(**預設為 `1234`,第一次使用請立即更改!**)
3. 設定頁內可以:
   - **編輯片單**:每條片有「台 / 名 / 影片 ID」三格。ID 一格直接貼上整條 YouTube 連結也可以,系統會自動抽取 ID
   - **分類**:「台」一欄填相同名字的影片會自動歸為同一個台,台名可加 emoji(例:📚 教育台)
   - **每日限時**:以分鐘為單位,填 0 代表沒有限制
   - **重設今日計時 / 更改密碼**

### 兩種更新片單的方式

| 方式 | 適合 | 效果 |
|---|---|---|
| App 內設定頁 | 日常加減影片 | 只影響該部裝置 |
| 修改 GitHub 上 `index.html` 的 `DEFAULT_VIDEOS` 段落 | 想所有裝置統一預設片單 | 影響所有「未在設定頁儲存過」的裝置 |

> 注意:裝置一旦在設定頁按過「儲存」,該裝置就會以自己的設定為準,不再讀取檔案內的預設片單。

## ❓ 常見問題

**Q:影片有廣告嗎?**
播放器使用 YouTube 官方嵌入式播放器,是否有廣告取決於該瀏覽器登入的 YouTube 帳號。登入了 YouTube Premium 帳號即無廣告。本 App 不含任何擋廣告功能(這會違反 YouTube 服務條款)。

**Q:可以離線觀看嗎?**
不可以。影片是經 YouTube 串流的,必須有網絡連線。

**Q:更新了片單但畫面沒變?**
瀏覽器快取問題。Windows 按 `Ctrl + F5` 強制重新載入;手機把 App 完全關閉再開啟。

**Q:忘記了家長密碼?**
清除該裝置瀏覽器中此網站的資料,密碼會還原為 `1234`(該裝置的片單設定也會一併還原為預設)。

**Q:小朋友會不會按 Home 鍵跳出去玩別的?**
App 本身鎖不住這個,請配合系統功能:iOS 用「引導使用模式」(設定 → 輔助使用 → 引導使用,按三下側邊鍵鎖定);Android 用「螢幕固定」;Windows 可按 F11 全螢幕。

**Q:某條影片播不了?**
可能原因:影片被上傳者設定為「不允許嵌入」、影片已被刪除、或影片為私人影片。換一條影片即可。
